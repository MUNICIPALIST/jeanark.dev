**Сделано.** Python-пакет (`core`, `api`, `cli`, `tests`), схемы контракта в `core/schemas.py`,
настройки в `core/config.py`, нормализация в `core/normalize.py`, контракты модулей в
`docs/build-plan.md`, CI, демо интерфейса в `frontend/`.

**Решения.**
- `.env` важнее окружения: в окружении лежит ключ бесплатного тарифа.
- Каталог артефактов задаётся через `ARTIFACTS_DIR`, чтобы рабочие копии делили одни артефакты.
- Язык определяем сами. Латиница на узбекском сервере получает ответ на uz, русская кириллица
  остаётся ru. Текст без букв считаем `und`.
- Замена букв cp1251 применяется только при признаках казахского в самом тексте. Регион сервера
  доказательством не считается: по итогам ревью условие `region == 'kz'` убрано, оно портило
  украинский текст на kz-серверах. Буквы қ, ғ, ґ, є, ї, ў сами по себе тоже не доказательство.

**Проверка.** `.venv/bin/python -m pytest -q`: 15 тестов проходят. На valid ответы пойдут на ru 859,
uz 134, kk 7, все 133 тикета региона uz получают uz. Демо собирается: `cd frontend && npm ci && npm run build`.

**Не сделано.** Кнопки демо не проверены кликами. На экране входа название продукта показано
дважды. Интерфейс не связан с API, это этап 6.

**Важно дальше.** Запускать код из корня рабочей копии через `python -m`, чтобы импортировался
именно её `core`. Рабочим копиям нужны ссылка на `.env` и `ARTIFACTS_DIR`.
