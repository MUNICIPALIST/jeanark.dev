`run.sh` для Linux и macOS, `run.ps1` и `run.bat` для Windows: окружение, зависимости и запуск одной командой. Пример входа: `examples/sample_tickets.txt`, выдуманные тикеты. В README раздел «Быстрый запуск».

Проверка: `run.sh` и `run.sh site` на чистой копии на macOS, shellcheck. `run.ps1` на настоящем Windows не запускался.
