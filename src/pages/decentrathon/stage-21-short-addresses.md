Всё работает на одном адресе, `демо-инстанс (выключен) а на нужный экран ведут короткие ссылки.

| Адрес | Экран | Кто открывает |
|---|---|---|
| `/admin`, `/queue` | очередь обращений | жюри, команда |
| `/check` | проверить обращение | жюри, команда |
| `/metrics` | метрики | жюри, команда |
| `/review` | проверка языка: казахский, узбекский, русский | гость, команда |
| `/label` | разметка настоящих тикетов | только команда |
| `/dashboard` | прогресс и результаты | только команда |

Без входа ссылка открывает форму на подходящей роли, после входа показывается запрошенный экран. Если роль его не
открывает, показывается её домашний экран. Сервер всё равно проверяет роль на каждом запросе данных: ссылка ничего
не открывает сама. `/admin/` со слешем перенаправляется на `/admin`: `index.html` подключает файлы относительными путями.

## Счётчик на экране проверки языка

Полоса считала только примеры, которые подтвердили два человека с разных сетей, поэтому первый проверяющий видел 0%
после 24 ответов. Теперь по каждому языку показано, сколько проверил сам человек, и отдельно сколько проверено всеми вместе и сколько
подтверждено двумя. Правило «два разных человека» не менялось.
