Цель: человек без контекста проверяет проект за 10 минут на сайте и у себя.

**README.** Сверху, сразу после заголовка, раздел «Для жюри: проверка за 10 минут»: путь по сайту с признаком
хорошего результата на каждом шаге; три способа запуска без ключа (`make predict`, `make serve` с интерфейсом, Docker) с
командами от `git clone` до результата и ожидаемым выводом; свои тикеты и пример строки в формате контракта; таблица
переменных (ничего не обязательно, для цитат нужна только `HANDOUT_DIR`); критерии кейса с числами из `docs/report.md`
(recall 0,641 и 0,587 против цели 0,70, цель не достигнута; человеческой разметки нет); шесть реальных сбоев с исправлением.
Старый «Быстрый старт для жюри» удалён как дубль. В «Запуске сервиса» убрано требование пароля для входа.

**`.env.example`.** Все строки с коротким комментарием, значения пустые (пустое значение ничего не меняет, `core/config.py`
его пропускает), перечислены только переменные из `core/config.py`. `cp .env.example .env` и запуск проверены.

**Карточка «С чего начать».** `frontend/src/FirstVisit.tsx`, над панелью статистики очереди, только для роли `jury`
(`guide={role === 'jury'}` в `main.tsx`), есть и в демо-сборке. Четыре шага, ссылки на «Проверить обращение» и «Метрики».
Закрытие запоминается в `localStorage` (ключ `copilot-guide-closed`), без хранилища карточка закрывается на этот визит.
Закрытая карточка это одна строка со ссылкой «С чего начать»: очередь не уходит с экрана. Ссылки на README нет: репозиторий
закрытый, адреса в документах не было.

**Проверка.** Чистый `git clone` ветки по HTTPS, новое окружение, без ключей в окружении: `make predict`, `make ui` и
`make serve` (интерфейс и `curl`), Docker (`docker compose -f docker-compose.local.yml up --build`, `make predict-docker`).
Экраны в headless Chromium: 1366x768, 1440x900, 390x844.
